# Models

Här ligger klasser som representerar det ni hanterar i hotellet (till exempel `Room` och `Booking`).

- En klass per fil, med samma namn som filen.
- Modeller innehåller data och enkel logik. De ska inte veta hur de sparas.
- Filerna `exempel_*.md` är exempel. Ta bort dem när ni lagt in era egna klasser.
